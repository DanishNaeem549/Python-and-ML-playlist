## ▶️ How to Run

Clone the repository

```bash
git clone https://github.com/yourusername/python-playlist.git
```

Move into the project

```bash
cd python-playlist
```

Run any Python file

```bash
python filename.py
```

or

```bash
python3 filename.py
```
